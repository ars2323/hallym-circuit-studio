# Hallym Circuit Studio 2.0.0-alpha.1

Hallym Circuit Studio 2의 두 번째 미리보기입니다. alpha.0은 열어 보기만 됐는데, 이번부터 **회로를 직접 그리고 고칠 수 있습니다**. 부품을 놓고, 선을 긋고, 옮기고, 복사하고, 되돌리기까지 원조 Logisim 2.7.1과 같은 방식으로 됩니다. 아직 미리보기이므로 과제는 지금처럼 v1.0.3 또는 원조 Logisim 2.7.1로 하고, 이 버전은 새 화면을 써 보는 데 써 주세요.

## 새로 바뀐 것

- **회로 편집:** 도구 모음의 Edit·Wire·Text·Pin·Tunnel·Probe 도구가 모두 됩니다. Components 목록에서 부품을 눌러 들고 Canvas를 누르면 놓입니다. 부품을 들고 있을 때 방향 키로 방향을, 숫자 키로 입력 수·비트 수를 바꿀 수 있습니다(원조와 같은 키).
- **고르기와 옮기기:** 클릭, Shift+클릭, 빈 곳에서 끌어 사각형으로 고릅니다. 고른 부품을 끌면 이어진 선이 따라옵니다(끄는 동안 Shift를 누르면 선 없이 옮깁니다). 방향 키로 한 칸씩 옮기고 R로 돌립니다.
- **선:** 포트나 선 끝의 초록 동그라미에서 끌면 선이 그어지고, 처음 움직인 방향으로 꺾입니다. 선을 따라 거꾸로 끌면 줄어듭니다.
- **편집 메뉴 키:** Delete, Ctrl+C·X·V(복사·잘라내기·붙여넣기), Ctrl+D(복제), Ctrl+Z·Ctrl+Y(되돌리기·다시 실행), Ctrl+A(모두 고르기), F2(라벨 바로 고치기). 입력 핀을 두 번 누르면 값을 적어 넣을 수 있습니다.
- **Attributes 칸:** 고른 부품의 이름·종류·자리가 나옵니다.
- **회로와 라이브러리:** Circuits 탭에서 회로를 더하고(Add Circuit), 지우고, 순서를 바꾸고, 다른 파일의 회로를 가져옵니다(Import). 서브회로의 모양을 Appearance 편집기로 바꾸고, Port Order로 포트 순서를 정합니다. Load Library로 Logisim 라이브러리와 JAR 라이브러리를 불러옵니다.
- **여러 파일과 창:** 파일마다 탭이 생기고, 탭을 떼어 따로 창으로 보거나 두 창을 나란히 볼 수 있습니다(View Side by Side). 바탕 화면의 `.circ` 파일을 창에 끌어 놓아도 열립니다.
- **갑자기 꺼져도:** 프로그램 안의 회로 계산 부분이 멈추면 스스로 다시 켜고, 저장하지 않은 편집을 그대로 다시 적용해 줍니다. 프로그램 전체가 꺼졌을 때는 저장해 둔 파일 옆의 복구 파일로, 그 파일을 다시 열 때 되살릴지 묻습니다.
- **설치 화면과 시작 화면:** 설치 파일이 진행 화면과 마침 화면을 보여 주는 안내형으로 바뀌었고, 시작 화면 뒤에 학교 홍보 영상의 첫 장면이 흐리게 나옵니다(Hallym MIPS Simulator 2.5.0과 같은 방식).
- **v1과 같은 결과:** 같은 편집을 하면 v1(Swing판)이 저장한 것과 같은 `.circ` 파일이 저장되는지 편집 장면 18개로 확인했습니다. 여기서 "같다"는 파일 내용이 같다는 뜻입니다(줄 앞 공백·빈 줄과, 한 회로 안에서 부품·선이 적힌 순서만 다를 수 있습니다). 저장한 파일은 원조 Logisim 2.7.1에서도 열립니다. Hallym MIPS 부품(Instruction Memory 등)을 쓴 파일은 그 파일과 같은 폴더에 `hcs-mips.jar`가 있어야 원조 2.7.1에서 열립니다.

## 받을 파일

| 파일 | 무엇 |
| --- | --- |
| `HallymCircuitStudio-2.0.0-alpha.1-win-x64-setup.exe` | Windows 설치 파일(이것 하나면 됩니다) |
| `hcs-mips.jar`, `hcs-mips-2.0.0-alpha.1-windows.zip` | 원조 Logisim 2.7.1에서 쓰는 MIPS 부품 라이브러리(트랙 A) |

## 설치

- 설치 파일을 받아 실행합니다. 진행 화면 뒤 "설치가 완료되었습니다" 화면에서 **지금 실행하기**가 체크된 채로 **마침**을 누르면 바로 열립니다. 관리자 권한도 Java도 필요 없습니다. 다음부터는 시작 메뉴에서 엽니다: **Hallym Circuit Studio**.
- **"Windows의 PC 보호" 창이 뜨면** 창에서 **추가 정보** → **실행** 순서로 누릅니다. 설치 파일에 코드 서명이 없어서 Microsoft Defender SmartScreen이 막는 것입니다. 받은 파일은 아래 SHA-256으로 확인할 수 있습니다.
- 1.0.x를 MSI로 설치한 PC에서는 예전 설치본을 조용히 지우고 설치합니다. 1.0.3 zip 폴더는 그대로 둡니다.
- 설치해도 `.circ` 파일의 연결 프로그램은 바뀌지 않습니다. 설정은 기억하지 않아 켤 때마다 기본값입니다(실습실 PC 규칙).
- 제거: 설정 › 앱에서 다음 항목을 제거합니다: **Hallym Circuit Studio 2.0.0-alpha.1**.

## 알려진 한계

- **속성 표와 우클릭 메뉴는 아직 없습니다.** 부품의 라벨·출력 핀 여부·크기·상수 값 같은 속성은 아직 바꿀 수 없습니다(숫자 키·Alt+숫자 키·방향 키·F2로 되는 것만 됩니다). Duplicate N, Align, Distribute 같은 우클릭 메뉴도 다음 미리보기에 들어갑니다.
- 시작 화면의 튜토리얼은 아직 없습니다(누르면 새 회로가 열립니다).
- 도구는 동작하지 않는 회로만 알립니다. 값이 흐르는데 결과가 틀린 회로는 판단하지 않습니다.
