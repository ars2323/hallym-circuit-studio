# Hallym Circuit Studio 2.0.0-alpha.0

Hallym Circuit Studio 2의 첫 **보기 전용 미리보기**입니다. 회로 파일을 열어 보고, 시뮬레이션을 돌리고, 동작을 Cycle View 칸과 Messages 칸에서 살펴볼 수 있습니다. **회로를 그리고 고치는 편집은 alpha.1부터** 됩니다. 과제는 지금처럼 v1.0.3 또는 원조 Logisim 2.7.1 프로그램으로 하고, 이 버전은 새 화면을 미리 써 보는 데만 써 주세요.

## 새로 바뀐 것

- 화면을 새로 만들었습니다(디자인은 Hallym MIPS Simulator 화면과 같음). 회로 계산은 그대로 Logisim 2.7.1 엔진이 합니다.
- **열기·보기:** `.circ` 파일을 열어 Canvas 화면에서 봅니다. 쓸 수 있는 것: 확대·축소, 이동, 회로 탭, 서브회로 안 보기, Find(Ctrl+F), Tunnels, Minimap.
- **시뮬레이션:** 쓸 수 있는 것: Run(F5), 1 Cycle(F10), Reset, 클럭 속도. 선 색으로 값이 보이고, Signal Flow 표시와 버스 값 표시도 됩니다.
- **Cycle View:** 사이클마다 값을 표로 보고, 지난 사이클로 돌아가 보고, Run Until 기능으로 원하는 곳까지 돌립니다. Registers·Memory·Instruction 칸도 있습니다.
- **Load Program:** Hallym MIPS 프로그램에서 내보낸 실행 이미지(`.hmx`)를 회로의 메모리에 올립니다. 프로그램이 출력한 글은 Console 칸에 나옵니다.
- **Messages:** 동작하지 않는 회로(연결 안 된 입력, 폭이 다른 선, 진동 등)를 학생이 붙인 이름과 위치로 알려 줍니다.

## 받을 파일

| 파일 | 무엇 |
| --- | --- |
| `HallymCircuitStudio-2.0.0-alpha.0-win-x64-setup.exe` | Windows 설치 파일(이것 하나면 됩니다) |
| `hcs-mips.jar`, `hcs-mips-2.0.0-alpha.0-windows.zip` | 원조 Logisim 2.7.1에서 쓰는 MIPS 부품 라이브러리(트랙 A) |

## 설치

- 설치 파일을 받아 실행합니다. 묻는 화면 없이 바로 설치되고, 관리자 권한도 Java도 필요 없습니다. 시작 메뉴에서 엽니다: **Hallym Circuit Studio**.
- **"Windows의 PC 보호" 창이 뜨면** 창에서 **추가 정보** → **실행** 순서로 누릅니다. 설치 파일에 코드 서명이 없어서 Microsoft Defender SmartScreen이 막는 것입니다. 받은 파일은 아래 SHA-256으로 확인할 수 있습니다.
- 1.0.x를 MSI로 설치한 PC에서는 예전 설치본을 조용히 지우고 설치합니다. 1.0.3 zip 폴더는 그대로 둡니다.
- 설치해도 `.circ` 파일의 연결 프로그램은 바뀌지 않습니다. 설정은 기억하지 않아 켤 때마다 기본값입니다(실습실 PC 규칙).
- 제거: 설정 › 앱에서 다음 항목을 제거합니다: **Hallym Circuit Studio 2.0.0-alpha.0**.

## 켤 때마다 처음부터

- 프로그램을 끄면 아무것도 남기지 않습니다. 창 크기, 패널 배치, 클럭 속도 같은 설정과 열었던 파일 목록을 기억하지 않아 켤 때마다 처음 상태로 시작합니다.
- 파일은 직접 저장한 곳에만 남습니다. 프로그램이 갑자기 꺼지면 저장해 둔 파일 옆에 복구 파일을 두고, 그 파일을 다시 열 때만 되살릴지 묻습니다.

## 알려진 한계

- **편집은 alpha.1부터:** 도구 모음의 편집 도구(Edit·Poke·Wire·Text·Pin·Tunnel·Probe)는 보이기만 하고 눌리지 않습니다. 선을 긋거나 부품을 옮기거나 입력 값을 바꿀(Poke) 수 없습니다.
- N Cycles 버튼은 아직 눌리지 않습니다. 여러 사이클은 Run 버튼이나 Cycle View 칸의 Run Until 기능으로 돌립니다.
- 시작 화면의 튜토리얼은 아직 없습니다(누르면 새 회로가 열립니다).
- 설치 화면은 아직 한 번에 설치하는 방식이고, 시작 화면의 배경 영상도 아직 없습니다. 둘 다 정식 버전 전에 Hallym MIPS 2.5.0 방식으로 바꿉니다.
- 도구는 동작하지 않는 회로만 알립니다. 값이 흐르는데 결과가 틀린 회로는 판단하지 않습니다.
