Hallym Circuit Studio 2.0.0-alpha.2, the third preview of Hallym Circuit Studio 2. This time you can try out **the new window layout, the attribute table and right-click menus, and choosing your course** first. It is still a preview, so do your assignments as before with v1.0.3 or original Logisim 2.7.1, and use this version to try the new window.

## Download (Windows 64-bit)

| File | What |
| --- | --- |
| `HallymCircuitStudio-2.0.0-alpha.2-win-x64-setup.exe` | The Windows installer (this one file is all you need) |
| `hcs-mips.jar`, `hcs-mips-2.0.0-alpha.2-windows.zip` | The MIPS part library for original Logisim 2.7.1 (track A) |

- Download the installer and run it. After the progress screen comes the "설치가 완료되었습니다" ("Installation complete") screen; leave **지금 실행하기** ("Run now") checked and click **마침** ("Finish") to open it right away. It needs no administrator rights and no Java. After that, open it from the Start menu: **Hallym Circuit Studio**.
- **If a "Windows protected your PC" window appears** (on Korean Windows: "Windows의 PC 보호"), click *More info*, then *Run anyway* (Korean Windows: **추가 정보** → **실행**). Microsoft Defender SmartScreen blocks it because the installer is not code-signed. You can check the downloaded file against the SHA-256 below.
- On a PC where 1.0.x was installed with the MSI, the old installation is removed quietly during setup. A 1.0.3 zip folder is left as it is.
- Installing does not change which program opens `.circ` files. Settings are not remembered, so every start uses the defaults (the lab PC rule).

## What you will see that is different

- **You choose your course first:** at every start the start card asks for the course: **논리설계 및 실험** (the logic design course) or **컴퓨터구조** (the computer architecture course). Then you choose [튜토리얼 보기] ("View the tutorial") or [바로 시작] ("Start now"), and with "Start now", [새 회로] ("New circuit") or [파일 열기] ("Open a file"). The course you chose is not remembered (the lab PC rule).
  - In the logic design course, the MIPS-only parts you don't study there (Instruction Memory, Data Memory, Console), Load Program…, the Registers, Memory and Instruction tabs of the Cycle View panel, and menus like Mark as PC are not shown. Radix Probe, which shows a value in hex, decimal and binary at once, is shown in both courses.
  - Click the course chip in the title bar to switch at any time. Only what is shown changes; the circuit and the simulation stay as they are.
  - If you open a file with computer architecture parts in the logic design course, the parts are drawn and work as usual, and a band at the top offers [컴퓨터구조로 바꾸기] ("Switch to the computer architecture course").
  - The Help › Examples list is per course too. The logic design course has new examples: a 1-bit adder, a 4-bit ripple-carry adder and a 4-bit counter.
- **A new start screen:** a dark glass bar and a translucent card over the university's video (the same look as Hallym MIPS Simulator 2.6.0). On the right of the title bar are the Menu, Tutorial, New, Open and Preferences icons; when a file is open, an Export Image… icon is added.
- **The window layout:** every command is in the title bar's menu (File, Edit, Project, Simulate, Window, Help). When the window is narrow, the items that do not fit in the toolbar and the status bar move into a » button. In a wide window the Canvas takes at least half of the window; in a narrow one you see the Canvas and the panels one side at a time.
- **The Attributes panel and Quick Attributes:** change a selected part's attributes, such as its label, facing, bit width and number of inputs, in the Attributes panel on the right. When you select a part, a small bar with its most used attributes (Quick Attributes) appears next to it. The bar is placed where it covers no part, wire or highlight.
- **Right-click menus:** right-click a part, a wire or an empty spot to get the commands for that place (Duplicate N…, Align, Distribute and more).
- **Preferences:** change display options and keyboard shortcuts in the Preferences window. Changes apply to this run only; the next start uses the defaults (the lab PC rule).
- **Other v1 features:** Undo History (see what you did and go back to a point), Create Submission… (make a submission file; your own file is not changed), Export Image… (PNG, SVG, PDF), Print…, Analyze Circuit (the truth table and expressions of a combinational circuit), Get Circuit Statistics (part counts).
- **Stability:** fixed a rare error when stepping back and forth quickly through recorded cycles, and a part dragged from the parts list sometimes not being placed.

## Known limits

- **The tutorial comes in the next preview.** For now, [튜토리얼 보기] ("View the tutorial") and the Tutorial icon in the title bar open a new circuit in the course you chose.
- Cycle 0, right after opening a file or clicking Reset, may occasionally not be recorded in the Cycle View table. It will be fixed before the final version.
- The screen wording and the user guide are still being polished.
- The tool reports only circuits that cannot work. A circuit whose values flow but whose result is wrong is not judged.
