# Hallym Circuit Studio 2.0.0-alpha.2

Hallym Circuit Studio 2 버전의 세 번째 미리보기입니다. 이번에는 **새 창 배치, 속성 표와 우클릭 메뉴, 교과목 선택**을 먼저 써 볼 수 있습니다. 아직 미리보기이므로 과제는 지금처럼 v1.0.3 또는 원조 Logisim 2.7.1 프로그램으로 하고, 이 버전은 새 화면을 써 보는 데 써 주세요.

## 새로 바뀐 것

- **교과목을 먼저 고릅니다:** 켤 때마다 시작 카드가 교과목을 묻습니다: **논리설계 및 실험** 또는 **컴퓨터구조**. 그다음 [튜토리얼 보기]·[바로 시작], 바로 시작이면 [새 회로]·[파일 열기]를 고릅니다. 고른 교과목은 기억하지 않습니다(실습실 PC 규칙).
  - **논리설계 및 실험**에서는 배우지 않는 MIPS 전용 부품(Instruction Memory, Data Memory, Console)과 Load Program…, Cycle View 칸의 Registers·Memory·Instruction 탭, Mark as PC 같은 메뉴가 보이지 않습니다. 값을 16·10·2진수로 함께 보는 Radix Probe 부품은 두 교과목 모두에서 보입니다.
  - 제목 줄의 교과목 칩을 눌러 언제든 바꿀 수 있습니다. 화면에 보이는 것만 바뀌고 회로와 시뮬레이션은 그대로입니다.
  - 논리설계 모드에서 컴퓨터구조 부품이 든 파일을 열면 부품은 그대로 그려지고 동작하며, 위쪽 띠에서 [컴퓨터구조로 바꾸기]를 누를 수 있습니다.
  - Help › Examples 목록도 교과목별입니다. 논리설계에는 1비트 가산기, 4비트 리플 캐리 가산기, 4비트 카운터 예제가 새로 들어갔습니다.
- **새 시작 화면:** 학교 영상 위에 어두운 유리 막대와 반투명 카드가 놓입니다(Hallym MIPS Simulator 2.6.0 버전과 같은 모양). 제목 줄 오른쪽에는 Menu, Tutorial, New, Open, Preferences 아이콘이 있고, 파일을 열면 Export Image… 아이콘이 더해집니다.
- **창 배치:** 제목 줄의 메뉴(File, Edit, Project, Simulate, Window, Help)에서 모든 명령을 찾을 수 있습니다. 창이 좁으면 도구 모음과 상태 표시줄의 넘치는 항목이 » 단추 안으로 들어갑니다. 창이 넓으면 Canvas 칸이 창의 절반 이상을 차지하고, 좁으면 Canvas 칸과 패널을 한쪽씩 봅니다.
- **Attributes 칸과 Quick Attributes:** 고른 부품의 라벨, 방향, 비트 수, 입력 수 같은 속성을 오른쪽 Attributes 칸에서 바꿉니다. 부품을 고르면 그 옆에 자주 쓰는 속성만 담은 작은 막대(Quick Attributes)가 뜹니다. 이 막대는 부품, 선, 강조 표시를 가리지 않는 자리에 놓입니다.
- **우클릭 메뉴:** 부품, 선, 빈 곳을 오른쪽 클릭하면 그 자리에 맞는 명령이 나옵니다(Duplicate N…, Align, Distribute 등).
- **Preferences:** 설정 창에서 보기와 단축키를 바꿀 수 있습니다. 바꾼 것은 이번 실행에만 적용되고, 다시 켜면 기본값입니다(실습실 PC 규칙).
- **그 밖의 v1 기능:** Undo History(되돌린 순서를 보고 그 지점으로 가기), Create Submission…(제출 파일 만들기, 학생 파일은 바꾸지 않음), Export Image…(PNG·SVG·PDF), Print…, Analyze Circuit(조합 회로의 진리표와 식), Get Circuit Statistics(부품 수 통계).
- **안정성:** 기록한 사이클을 빠르게 앞뒤로 볼 때 드물게 오류가 나던 것, 부품 목록에서 끈 부품이 놓이지 않던 것을 고쳤습니다.

## 설치

- 설치 파일을 받아 실행합니다. 진행 화면 뒤 "설치가 완료되었습니다" 화면에서 **지금 실행하기**가 체크된 채로 **마침**을 누르면 바로 열립니다. 관리자 권한도 Java도 필요 없습니다. 다음부터는 시작 메뉴에서 엽니다: **Hallym Circuit Studio**.
- **"Windows의 PC 보호" 창이 뜨면** 창에서 **추가 정보** → **실행** 순서로 누릅니다. 설치 파일에 코드 서명이 없어서 Microsoft Defender SmartScreen이 막는 것입니다. 받은 파일은 아래 SHA-256으로 확인할 수 있습니다.
- 1.0.x를 MSI로 설치한 PC에서는 예전 설치본을 조용히 지우고 설치합니다. 1.0.3 zip 폴더는 그대로 둡니다.
- 설치해도 `.circ` 파일의 연결 프로그램은 바뀌지 않습니다. 설정은 기억하지 않아 켤 때마다 기본값입니다(실습실 PC 규칙).
- 제거: 설정 › 앱에서 다음 항목을 제거합니다: **Hallym Circuit Studio 2.0.0-alpha.2**.

## 알려진 한계

- **튜토리얼은 다음 미리보기에 들어갑니다.** 지금은 [튜토리얼 보기]나 제목 줄의 튜토리얼 아이콘을 누르면 고른 교과목의 새 회로가 열립니다.
- 파일을 열거나 Reset을 누른 바로 뒤의 사이클 0이 Cycle View 표에 가끔 기록되지 않을 수 있습니다. 고친 뒤 정식 버전을 냅니다.
- 화면 문구와 안내서는 아직 다듬는 중입니다.
- 도구는 동작하지 않는 회로만 알립니다. 값이 흐르는데 결과가 틀린 회로는 판단하지 않습니다.
