# 화면 품질 체크리스트

모든 UI 작업과 UI 변경 PR에 적용한다. ui-reviewer(`.claude/agents/ui-reviewer.md`)가 스크린샷을 보고 이 목록으로 검토한다.

1. **겹침 금지:** 라벨 칩, 스플리터 팔 라벨, 서브회로 캡션, 포트 이름 덧그림, 빠른 속성 창, 팝업, 툴팁이 가리지 않는다. 가리면 안 되는 것은 선, 포트, 다른 칩, 부품 글자, 값 표시다.
2. **끊겨 보임 금지:** 연결된 선이 화면에서 끊겨 보이면 안 된다. 칩 밑을 지나는 선은 칩 위에 다시 그리거나 칩을 반투명으로 한다. 연결 없는 교차는 반원 점프, 연결점은 큰 점으로 그린다.
3. **언어(D-049):** 이름·명령은 영어(원조 2.7.1 용어), 설명 문장만 한국어로 쓴다. 단수·복수를 정확히 쓴다.
4. **배율:** 25%·100%·400%에서 글자와 표시가 읽힌다. 누른 항목과 누르지 않은 항목의 굵기가 구분된다.
5. **원조 비교:** 캔버스 그림이 바뀌는 기능은 같은 장면을 원조 2.7.1로 찍어 나란히 둔다. 우리 덧그림 밖 영역은 원조와 같아야 한다.
6. **프로그램이 일으킨 선택·이동 뒤:** 메시지 클릭, 찾기, 영향 경로, 사이클 이동, 되돌리기가 해당한다. 속성 패널은 선택을 따라가고, 빠른 속성 창은 뜨지 않는다.
7. **군더더기 금지:** 도구가 만든 선에 같은 넷 안 고리, 막다른 짧은 선, 일직선으로 쪼개진 조각이 남지 않는다.
8. **결정성:** 같은 회로·같은 조작은 어느 PC에서나 같은 결과를 낸다. 시간 제한에 의존하는 동작은 금지한다.
9. **원칙:** 동작하지 않는 회로만 알린다. 동작하지만 틀린 회로는 판단하지도, 비교하지도 않는다.
10. **스크린샷용 회로:** 사람이 그린 회로(demo-datapath 등)를 쓴다. 자동 생성 회로(ref-mips)는 정확성 테스트용이다.
11. **빈 공간:** 화면 맞춤은 회로 전체를 가로·세로 모두 기준으로 여백을 두고 가운데 맞춘다. 패널에 쓸모없는 넓은 빈 영역을 두지 않는다.

## 테스트 원칙

- **기대 결과는 고정값이다.** "N번 중 M번 이상" 같은 임계값 테스트는 금지한다. 결과가 흔들리면 원인을 없앤다.
- **편집 기능이 확인할 것:**
  - 넷리스트가 그대로다(또는 의도한 변화만 있다).
  - 새 선이 부록 A.4 규칙을 지킨다.
  - 되돌리기 한 번에 원상복구된다.
  - 새 부품이 없는 .circ는 원조 2.7.1과 바이트 호환(D-006)이고 의미도 같다.
- **실제 창이 필요한 동작은 guiTest(Xvfb)로 확인한다.** 시뮬레이터 스레드와 편집이 겹치지 않게 한다.
- **정상 회로 Messages 0건은 매 PR 필수다.** 대상: 엔진 회귀, demo-datapath, ref-mips, 이후 과제 회로.
- **성능:** docs/PERFORMANCE.md의 상한을 CI가 지킨다.
