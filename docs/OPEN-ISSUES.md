# 남은 일(OPEN-ISSUES)

릴리스를 막지 않아 다음 라운드로 넘긴 것과, 결정은 났지만 뒤 라운드에서 할 일을 모은다.
검토 등급은 `docs/UI-CHECKLIST.md` "판정 등급"을 따른다: **넘김**(3px 이하 간격, 정렬 같은 모양 다듬기)은 여기에 적고 다음 라운드에서 모아 고친다.
고치면 줄을 지우지 말고 상태를 "고침(PR 번호)"으로 바꾼다.

**v2 전환(2026-09-27, D-132):** 화면 항목(U-*, O-01·O-02·O-03·O-05·O-07)은 Swing 화면에서 나온 것이라 상태를 "v2에서 다시 만듦"으로 둔다. v2 화면을 만든 뒤 N-25에서 v2 기준으로 다시 보고, 고친 PR이나 근거를 적어 닫는다.
