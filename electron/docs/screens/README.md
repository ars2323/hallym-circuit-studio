# Screens — the fixed set

Every round, **all of them are retaken and overwritten** under the same names; no subfolders. All are taken by `tools/capture-screens.ts` (none by hand), with the fake engine (`tests/fake-engine/fake-engine.ts`), whose answers are fixed: the same code gives the same pixels. The files and steps are written inside the tool.

- To retake: in `electron/`, `xvfb-run -a -s '-screen 0 2400x1400x24' npm run screens` (Linux, Xvfb software rendering). **The same code gives the same pixels (D-158):** `node tools/capture-screens.ts --twice` takes every scene again into a temporary folder and fails unless each PNG is the same bytes. Every window of the tool emulates prefers-reduced-motion and has no transition, animation or blinking caret; a shot waits on explicit signals (fonts and images loaded, no engine call of the window's outstanding, the Canvas settled, two frames), never on a guess of time; Chromium rasterises on the CPU, whole tiles, one thread. The scenes with the real engine need `./gradlew :engine:stage` and a Java 21 (`HCS_JAVA` or `JAVA_HOME`).
- Default: the whole window at **1920×1032** CSS px at 100 % — a 1920×1080 lab PC with the window maximised over a 48 px taskbar. No mouse cursor, tooltip or hover (the pointer is moved out of the window and `:hover` is checked to be 0); focus is cleared; every image has loaded.
- Size: 1.5 MB or less each (they are 50–160 KB). Metadata (ancillary PNG chunks) is stripped; lossless. Over the limit, the tool stops.
- The window buttons (minimise, maximise, close) are drawn by the system on the title bar's right end (`titleBarOverlay`), so a page capture has none: their place is empty.
- The Canvas draws the circuit (N-05, D-137); the fake engine answers `demo-datapath` and `ref-mips` from the engine-made fixtures (`tests/fixtures/circuits/`), so the drawings and their values are the real engine's.
- The overlays (N-15, D-151) use the real engine's answers too: `tests/fixtures/flow/demo-datapath.json` (influence, Signal Flow, active path, field arms, net information; `./gradlew :engine:canvasFixtures`). Bus value chips show on every Canvas (Hex at start).
- The Cycle View's scenes use the fake engine's recording (`tests/fake-engine/fake-record.ts`): a file with an Instruction Memory runs the recursive factorial one instruction a cycle, so PC, the registers and the stack move as a single-cycle CPU's would; the rows' values are a fixed pattern.
